# 도토리 숲 수학 퀴즈

초등 1~6학년 수학을 동물 친구들과 함께 익히는 학습 앱입니다.
바로 쓰기: https://goodjobman-eng.github.io/dotori-math/

- **비영리·교육 목적**으로 만든 사이트입니다. 학교·가정에서 자유롭게 쓰세요.
- 직접 만져 보는 조작 문제 → 기본 익히기 → 이야기 문제 → 도전 문제 차례로 풉니다.
- 틀린 답마다 "왜 틀렸는지"(오개념)를 짚어 다음 문제를 고릅니다.
- 이름·학교·반 같은 개인 정보는 받지 않습니다.

## 고쳐 쓰기

`index.html` 한 파일로 돌아갑니다. 원본은 `kt-src/`에 있고, `python3 build.py`로 다시 만듭니다.
