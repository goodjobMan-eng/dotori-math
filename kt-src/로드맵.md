# 27. 교사가 옆에 없어도 배우는 코스웨어 — 로드맵

2026-11-21. 교수님 지시: "종래에는 초등교사가 없어도 되는 수준으로 발전시켜 봐."
목표를 이렇게 잡는다: **교사가 옆에 없어도 아이가 혼자서 막힌 곳을 찾고, 배우고, 다시 확인할 수 있다.**

## 1. 교사가 하는 일과 지금 앱 (2026-11-21 기준)
| 교사가 하는 일 | 지금 앱 | 판정 |
|---|---|---|
| 어디서 막혔는지 찾기 | 오개념 코드 258개, 개념 조각 63개, 수준 찾기, 확인 문제, 아래 학년 찌르기 | 됨 |
| 개념을 처음 가르치기 | 영상(시즌 1 51편, 시즌 2~ 제작 중). 영상이 없는 조각은 '준비 중'으로 비어 있음 | 일부 |
| 틀린 그 자리에서 고쳐 주기 | 오개념 한 줄 도움말, 두 번 틀리면 풀이 순서. 아이가 쓴 답을 짚어 주지는 않음 | 약함 |
| 쉬운 데로 내려갔다 올라오기(비계) | 같은 조각의 문제를 더 냄. 수를 줄이거나 그림·빈칸 식으로 단계를 낮추지 않음 | 없음 |
| 왜 그런지 말하게 하기 | 없음 | 없음 |
| 연습량·복습 간격 정하기 | 오늘의 문제, 다시 다지기, 정보량으로 문제 고르기 | 됨 |
| 수학 밖의 까닭 가리기(읽기, 조작 실수, 찍기) | 읽어 주기 일부, 3초 안 정답 제외, 빈 상자 차단 | 일부 |
| 의욕·습관 | 캐릭터 칭찬, 내 친구 고르기 | 약함 |
| 보호자에게 알리기 | 교사용 화면뿐(교사 용어) | 없음 |
| 문항·판정이 맞는지 살피기 | 검산 도구 다수, 카본 교차 검토. 실제 아이 데이터로는 한 번도 맞춰 보지 않음(서버 미배포) | 약함 |

가장 큰 빈칸은 **가르치기**다. 진단은 교사만큼 하는데, 찾아낸 뒤에 할 일이 '영상 보기'와 '문제 더 풀기'뿐이다.

## 2. 단계
### 1단계: 틀리면 그 자리에서 가르친다
1. **개념 카드**: 조각 63개마다 3장짜리 작은 수업(구체물 그림 → 식으로 옮기기 → 빈칸 따라 풀기). 영상이 없는 조각에서 영상 자리를 대신하고, 영상이 있어도 '다시 보기'로 쓴다.
2. **오답 맞춤 설명**: "네 답 885는 일의 자리에서 올린 1을 더하지 않았을 때 나와요"처럼 아이가 낸 수로 말한다. 오개념 코드마다 문장 틀.
3. **비계 사다리**: 오개념이 확인되면 같은 문제를 ① 작은 수 ② 그림과 함께 ③ 단계 빈칸 식으로 내려 주고, 맞히면 원래 수준으로 올라온다. 오늘 만든 '식의 빈칸 채우기'를 이 사다리의 한 칸으로 쓴다.
4. **고쳐졌는지 확인**: 지금의 3판 2선승 확인 문제를 그대로 쓰되, 카드를 본 뒤의 정답률을 카드별로 남긴다(강의 A/B와 같은 방식).

### 2단계: 혼자서 이어 간다
5. 보호자용 한 장: "이번 주에 한 것 / 아직 어려운 것 / 집에서 도울 것 한 가지"를 교사 용어 없이.
6. 막힘 감지: 오래 멈춤, 연속 찍기, 같은 오답 되풀이를 알아채고 문제를 바꾸거나 쉬어 가게 한다.
7. 모든 문제 읽어 주기(지금은 녹음 있는 문장만), 긴 문장제는 끊어 읽기.
8. '왜 그럴까?' 한 번 더 묻기: 맞힌 뒤 이유 고르기(이유 보기도 오개념에서 만든다).

### 3단계: 스스로 고친다
9. 서버 배포 → 실제 응답으로 보기 무게, 문항 난이도, 오개념 판정 기준을 다시 맞춘다.
10. 효과 없는 카드·영상·문항을 자동으로 표시한다(본 뒤에도 정답률이 안 오르는 것).

## 3. 솔직한 한계
- 앱이 대신할 수 있는 것은 진단, 설명, 연습, 확인이다. 정서와 관계, 또래와 말로 따지기, 실물 조작, 그리고 **앱이 틀렸을 때 알아채는 사람**은 대신하지 못한다.
- "교사 없이도 된다"는 말은 실제 아이들 기록으로만 증명된다. 지금은 가상 아이로만 시험했다. 그래서 3단계의 서버 배포(교수님 몫)가 사실상 맨 앞 조건이다.
- 1~2학년은 혼자 글을 읽기 어려워 읽어 주기와 어른 한 명이 여전히 필요하다.

## 4. 진행 (2026-11-22)
- 1단계 ① 개념 카드: 63개 조각 모두(11/22 완성). 영상이 12월 6일 전 모두 올라오므로 카드의 주 역할은 '영상 뒤에도 비어 있을 때'와 '같은 실수 두 번일 때'.
- 1단계 ③ 비계 사다리: 같은 조각 오답 두 번 → 카드 + 같은 꼴 문제. 연속 오답 세 번 → 카드.
- 1단계 ④ 카드 효과 기록: 카드 뒤 같은 꼴 문제를 방식 's'로 기록.
- 2단계 ⑤ 보호자용 한 장: 완료.
- 남음: 1단계 ② 아이가 낸 수로 말하는 오답 설명, 카드 마지막 장을 핵심 단계 빈칸으로, 카본 2차 검토(도형·규칙·자료 카드), 2단계 ⑥~⑧, 3단계(서버 배포가 먼저).

## 5. 처음 적었던 다음 할 일
- 1단계 ① 개념 카드 엔진 + 수와 연산 조각(C01~C30)부터 10개씩.
- 카본이 지적한 두 가지: 단위 하나짜리 답도 상자 하나로, km·m 덧뺄셈 수 조합 바꾸기.
