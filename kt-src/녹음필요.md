# 다시 녹음할 음성 조각 (2026-11-21)

1~2학년 음성 글의 조사·읽기를 바로잡으면서, 아래 문구는 녹음이 없어 그 문장만 기계음(브라우저 TTS)으로 나온다.
ElevenLabs로 추가 녹음해 `VOICE`에 넣으면 다시 캐릭터 목소리로 나온다(절차: 프로젝트 문서 08_퀴즈앱_음성뱅크).
`node x23.js`를 돌리면 지금 기계음으로 떨어지는 문장 꼴 전체가 나온다.

| 캐릭터 | 새로 필요한 문구(수 낱말 바로 뒤에 붙는 조각) | 쓰이는 곳 |
|---|---|---|
| 도토 | `이 될까요?` / `가 될까요?` | 34편 □ + a = t |
| 람이 | `이 될까요? 몇 개가 사라졌을까?` / `가 될까요? 몇 개가 사라졌을까?` | 34편 t − □ = a |
| 람이 | `는 숫자로 어떻게 쓸까요?` | 1편 '하나는 숫자로' (은 → 는) |
| 청이 | `이 될까? 보자기 밑에 몇 개가 숨었을까?` / `가 될까? 보자기 밑에 몇 개가 숨었을까?` | 34편 a + □ = t |
| 청이 | `이 될까? 접시가 몇 개인지 세어 봐.` / `가 될까? 접시가 몇 개인지 세어 봐.` | 43~50편 구구단 □ |
| 청이 | `이 될까? 빈칸에 들어갈 수를 찾아보렴.` / `가 될까? 빈칸에 들어갈 수를 찾아보렴.` | 34편 빈칸 쓰기 |
| 할머니 | `이 된단다. 어떤 수일까?` / `가 된단다. 어떤 수일까?` | 34편 □ − a = x |
| 할머니 | `으로 가를 수 있을까? 빈칸에 들어갈 수를 찾아보렴.` | 7~14편 가르기 식(삼·육·십 뒤) |

그대로 둔 것: "바구니 한 개, 낱개 영 개"(0을 '영 개'로 읽음). 뜻은 통하고, 바꾸면 이 문장도 기계음이 되어 보류.
