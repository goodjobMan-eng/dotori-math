# 익명 학습 기록 수집 — 설치와 보안

## 흐름

1. 앱은 기록을 기기 안(localStorage)에 쌓는다. 진단과 코스 추천은 기기 안에서 끝난다.
2. 교사가 켠 기기만(`주소#kt-share-on`) 하루 한 번 이하, 응답 50건 이상일 때, 앱을 닫는 순간 묶음 하나를 보낸다. 전송 시각은 기기마다 0~6시간 무작위로 늦춘다.
3. 서버(Cloudflare Worker)는 검사를 통과한 묶음만 비공개 R2 저장소에 `raw/날짜/기기번호.json`으로 쌓는다.
4. 한 달에 한 번 `export_public.py`로 정리해 공개 데이터셋(CC BY 4.0)으로 올린다.

## 설치

1. Cloudflare 계정을 만들고 2단계 인증을 켠다.
2. R2에서 `dotori-kt-raw` 버킷을 만든다. 공개 접근(Public access)은 켜지 않는다.
3. 이 폴더에서 `npx wrangler deploy`.
4. 나온 주소를 앱 `kt.js`의 `KT_ENDPOINT`에 `https://<주소>/v1/ingest`로 넣는다.

## 기록 형식 (v2)

한 줄 = `[날짜, 편, 틀 번호, 종, 시드, 낸 답, 정답 여부, 오개념 코드, 걸린 시간(ms), 진단 문항 여부]`

## 아직 해결하지 않은 것

- 하루 총량 상한이 없다(가짜 묶음으로 저장소를 채울 수 있음). 배포 전에 넣어야 한다.
- 앱은 전송이 실제로 성공했는지 확인하지 못한다(sendBeacon). 거절되면 그 묶음은 사라진다.
- 이 서버 코드는 모의 환경에서 검사 규칙만 시험했고, 실제 Cloudflare에 배포해 본 적이 없다. 속도 제한 설정 문법도 배포 때 확인이 필요하다.

## 보안 점검표

| 위험 | 막는 방법 | 위치 |
| --- | --- | --- |
| 아이 이름·반·번호가 들어감 | 앱은 그런 칸을 만들지 않음. 서버는 정해진 4칸(`v, did, day, recs`) 외의 칸이 하나라도 있으면 거절 | `worker.js` |
| 답 칸에 전화번호 같은 글을 적어 보냄 | 답은 24자, 허용 문자만. 오개념 코드·에피소드 번호는 형식 검사 | `kt.js clean()`, `worker.js RE` |
| 기기 번호로 아이를 알아냄 | 기기 번호는 앱이 만든 난수. 화면에 보여 주지 않음. 교사도 번호-이름 표를 만들지 않음. `#kt-reset`으로 새로 만들 수 있음 | `kt.js did()` |
| 공개 데이터에서 특정 기기·학급 찾기 | 공개본에는 날짜를 넣지 않고 그 기기의 '며칠째'만 남김. 기기 번호는 비밀 소금값으로 해시. 소금값은 저장소·데이터에 넣지 않음 | `export_public.py` |
| 문제 내용을 글로 보내면 이름 등이 섞일 수 있음 | 문제 글은 보내지 않음. (편, 틀 번호, 종, 시드)만 보내고, 공개 소스로 같은 문제를 다시 만듦 | `kt.js regen()` |
| 서버에 IP·브라우저 정보가 쌓임 | 저장하지 않음. 속도 제한에서 IP는 세기만 함. Worker 로그(관측) 기능은 끄고 둠 | `worker.js`, `wrangler.toml` |
| 서버 폭주·도배 | 기기당 하루 1묶음(두 번째는 409), 묶음 200KB·2,000건 상한, IP당 1분 20번 | `worker.js` |
| 다른 사이트가 우리 서버로 보냄 | Origin이 앱 주소가 아니면 거절 | `worker.js` |
| 가짜 데이터로 통계 오염 | 공개본 만들 때 응답 0.3초 미만이 대부분이거나 하루 1,500건 넘는 기기 등 제외 | `export_public.py` |
| 원본 데이터 유출 | R2는 비공개, 읽기 API 없음. 관리자 계정 2단계 인증. 원본은 Cloudflare 계정으로만 접근 | 운영 |
| 비밀 키 노출 | 앱에는 비밀 값이 없음(공개 웹앱이라 넣어도 보임). 비밀 값은 소금값 하나뿐이고 관리자 컴퓨터에만 둠 | 운영 |

알려진 한계: 앱 주소를 흉내 내는 요청은 Origin 검사만으로 완전히 막을 수 없다. 그래서 하루 1묶음·속도 제한·공개 전 걸러내기를 함께 둔다. 공개 전에 학교 또는 교육청 개인정보 담당자에게 한 번 확인받는다.

## 방식 칸(12번째)의 글자
u 일반 · g 수준 찾기 · f 골라 풀기 · d 오늘의 문제 · q 빠른 풀이 · r 복습 · k 확인 문제 · A/B 강의 순서 측정 · p 찌르기(확인 안 된 아래 학년 개념 탐색) · n 이어 묻기(코드 없는 오답 바로 뒤의 객관식)

## 개인 구분
기기마다, 그리고 같은 기기 안의 '내 친구'(색깔 동물)마다 무작위 번호(did)가 따로 만들어진다. 친구 이름·색·동물은 보내지 않는다. 공개용 변환(export_public.py)에서 did는 소금 넣은 해시 앞 16자로 바뀐다.
