# kt-src — 지식추적·새 화면 소스

`index.html`은 원본 앱(커밋 ed336e7의 index.html)에 이 폴더의 소스를 붙여 만든 결과물입니다.

- `kt_v1.js`, `src/bank2.js`: 오개념 진단 문항
- `src/mis.js`, `src/tags3.js`: 오개념 코드 표, 기본 문제의 보기·오개념 태그
- `src/core2.js`, `src/facts.js`, `src/modes.js`: 지식추적, 단순 지식 되풀이, 푸는 방법·학년 화면
- `src/assets2.js`: 캐릭터·장소 그림
- `build.py`: 원본 index.html에 위 파일을 붙여 새 index.html을 만듦(원본 경로는 파일 안에서 고쳐 쓰세요)
- `server/`: 익명 기록 수집용 Cloudflare Worker(아직 배포 전)
